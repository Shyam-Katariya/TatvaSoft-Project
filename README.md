# Bookstore Application

A React-based bookstore application maintained as part of the TatvaSoft project work.

The application source is located in the `Bookstore-main/` directory.

## Technology

- React 18
- React Router 6
- Material-UI 4
- Axios
- Formik and Yup
- React Toastify

## Project structure

```text
.
├── Bookstore-main/
│   ├── public/
│   ├── src/
│   ├── package.json
│   └── README.md
└── README.md
```

## Run locally

```bash
cd Bookstore-main
npm install
npm start
```

The development server runs at [http://localhost:3000](http://localhost:3000).

## Available scripts

| Command | Purpose |
|---|---|
| `npm start` | Start the development server |
| `npm test` | Run the test runner |
| `npm run build` | Create a production build |

## Notes

This repository contains the application in a nested directory. Existing source files and project configuration are retained.
